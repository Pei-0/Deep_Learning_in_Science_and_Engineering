# 113-1 NTU 深度學習在科學與工程上的應用

此 repository 整理了 **113-1 深度學習在科學與工程上的應用** 這門課的所有作業。

## 課程大綱

本課程介紹深度學習的基本原理，以及其相關的數學建模與方法，學習如何運用深度學習技術來解決科學與工程領域中的問題。

在課程中，主要使用 **PyTorch** 實作深度學習模型，並透過多個實例了解深度學習在科學與工程中的應用。

課程內容也簡要介紹深度學習領域的最新發展與研究趨勢。

內容涵蓋...
- 深度學習基本原理  
- 深度學習的數學建模方法  
- 使用 PyTorch 進行模型實作  
- 深度學習在科學與工程中的應用案例  
- 深度學習的最新研究進展
